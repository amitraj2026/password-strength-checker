# password-strength-checker
Password Strength Checker 🔐

A beginner-friendly Python project that checks password strength based on multiple security conditions. This project was built while learning Python Strings and Functions and helped me understand how to break a problem into reusable functions.

Features:

✅ Checks password length
✅ Checks uppercase letters
✅ Checks lowercase letters
✅ Checks numbers
✅ Checks special characters
✅ Calculates password strength

Concepts Used:
Strings • Functions • Loops • Conditional Statements • User Input
